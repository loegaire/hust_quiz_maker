- Biểu thức `32*sin(c)` hoặc `128*sin(c)` không thay đổi trong vòng lặp nên có thể tính trước ngoài vòng lặp.
- Rút gọn biểu thức toán học: `4*b*b + 12*b + 9` có thể viết lại thành `(2*b + 3) * (2*b + 3)`. Biểu thức `b*b - 2*c*b + c*c` có thể viết thành `(b - c) * (b - c)`.

Q: (TỰ LUẬN)
Ngữ cảnh: Một lập trình viên viết chương trình C để quản lý tự động danh sách thống kê GPA của sinh viên theo các mã lớp (ví dụ: IT1-K69, IT1-K70). Vì số lượng lớp là không xác định trước, người này quyết định sử dụng mảng động và dùng realloc để mở rộng mảng khi cần thiết.

Yêu cầu: Đọc kỹ đoạn mã nguồn C dưới đây. Hãy cho biết đoạn chương trình này có lỗi hay không?
- Nếu có, hãy chỉ ra chi tiết từng lỗi, giải thích nguyên nhân gây lỗi (có thể dẫn đến hiện tượng gì trong RAM) và viết lại đoạn code để sửa toàn bộ các lỗi đó.
- Nếu không, hãy giải thích chi tiết cơ chế hoạt động của realloc và vòng đời của bộ nhớ trong đoạn code này.

```cpp
c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

    typedef struct {
  char* class_code;
  int student_count;
  float average_gpa;
} CohortStat;

// Hàm bổ sung thêm một bản ghi thống kê vào mảng động
void appendStat(CohortStat* stats_array, int* current_size, int* max_capacity,
                const char* code, int count, float gpa) {
  if (*current_size >= *max_capacity) {
    *max_capacity *= 2;  // Mở rộng vùng nhớ khi mảng đã đầy
    stats_array =
        (CohortStat*)realloc(stats_array, (*max_capacity) * sizeof(CohortStat));
    if (stats_array == NULL) {
      printf("Loi cap phat bo nho!\n");
      return;
    }
  }
  // Cấp phát động cho chuỗi ký tự và lưu thông tin
  stats_array[*current_size].class_code =
      (char*)calloc(strlen(code) + 1, sizeof(char));
  strcpy(stats_array[*current_size].class_code, code);
  stats_array[*current_size].student_count = count;
  stats_array[*current_size].average_gpa = gpa;
  (*current_size)++;
}

int main() {
  int capacity = 2;
  int size = 0;
  // Khởi tạo mảng thống kê ban đầu chứa được 2 phần tử
  CohortStat* report = (CohortStat*)calloc(capacity, sizeof(CohortStat));
  // Nạp dữ liệu
  appendStat(report, &size, &capacity, "IT1-K69", 120, 3.2f);
  appendStat(report, &size, &capacity, "IT1-K70", 135, 3.1f);
  // Lần gọi thứ 3 này sẽ vượt quá capacity (2) và kích hoạt realloc
  appendStat(report, &size, &capacity, "IT2-K69", 90, 3.0f);
  // In kết quả
  printf("\n--- BAO CAO THONG KE ---\n");
  for (int i = 0; i < size; i++) {
    printf("Class: %s, Count: %d, GPA: %.2f\n", report[i].class_code,
           report[i].student_count, report[i].average_gpa);
  }
  // Dọn dẹp bộ nhớ
  free(report);
  return 0;
}
```
Ans: ['Tự luận']
Exp: Các lỗi nghiêm trọng trong chương trình C này:
```cpp
1. Địa chỉ mảng động bị mất khi dùng `realloc` trong hàm: Con trỏ `stats_array` được truyền bằng trị. Khi `realloc` di chuyển mảng sang vùng nhớ mới, địa chỉ mới được lưu vào tham số cục bộ `stats_array`. Nhưng biến `report` ở `main` không hề được cập nhật địa chỉ mới này. Khi trở về `main`, `report` vẫn trỏ tới địa chỉ cũ đã bị giải phóng, gây ra hành vi không xác định (Undefined Behavior) hoặc lỗi phân đoạn (Segmentation fault) khi truy cập hoặc giải phóng `free(report)`.
```
- Cách sửa: Truyền tham chiếu địa chỉ `CohortStat** stats_array` và thao tác với `*stats_array`.
```cpp
2. Rò rỉ bộ nhớ (Memory Leak): Chuỗi `class_code` được cấp phát động bằng `calloc` nhưng không được giải phóng trước khi `free(report)` giải phóng toàn bộ mảng.
- Cách sửa: Duyệt qua mảng và gọi `free(report[i].class_code)` trước khi `free(report)`.
```
